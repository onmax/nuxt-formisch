The three Formisch composables are auto-imported. They are the same functions as in [`@formisch/vue`](https://formisch.dev/vue/api/), so Formisch's own guides apply as written.

## useForm

Creates the form store from a Valibot object schema.

```ts
const form = useForm({
  schema: ProfileSchema,
  initialInput: { name: 'Ada' },
  validate: 'submit', // default
  revalidate: 'input', // default
})
```

| Option | Description |
| --- | --- |
| `schema` | Valibot object schema. Required. |
| `initialInput` | Starting values. Fields without one start empty (`''` for strings). |
| `emptyInput` | The value a field gets when it has no input, per schema type, for example `{ string: undefined }`. |
| `validate` | When to validate first: `'initial'`, `'touch'`, `'input'`, `'change'`, `'blur'` or `'submit'`. |
| `revalidate` | When to validate again after that. Same modes, except `'initial'`. |

The store is reactive. Read its state in templates and computed values:

| Property | Meaning |
| --- | --- |
| `isSubmitting` | The submit handler is running. |
| `isSubmitted` | The form was submitted at least once. |
| `isValidating` | Validation is running. |
| `isTouched` / `isEdited` / `isDirty` | A field was focused / changed / differs from its initial input. |
| `isValid` | No field has an error. |
| `errors` | Errors on the root object only. Use [`getDeepErrors`](/forms/methods) for every field. |

## useField

Connects one field. Use it inside an input component that renders a single field; for several fields in one template, [`<FField>`](/forms/components#ffield) is simpler.

```vue [app/components/EmailInput.vue]
<script setup lang="ts">
import type { FormStore } from '@formisch/vue'

const props = defineProps<{ form: FormStore<typeof LoginSchema> }>()

const field = useField(() => props.form, { path: ['email'] })
</script>

<template>
  <label>
    Email
    <input v-model="field.input" v-bind="field.props" type="email">
  </label>
  <p v-if="field.errors">{{ field.errors[0] }}</p>
</template>
```

Both arguments accept a value, a ref or a getter. Pass a getter when the form or path comes from props, so the field follows them.

The field store has `input`, `errors`, `props`, `path`, `isTouched`, `isEdited`, `isDirty` and `isValid`. Paths are arrays: `['user', 'email']` for nested objects, `['todos', 0, 'label']` for array items.

## useFieldArray

Tracks a list. `items` holds a stable key per entry, so `v-for` keeps each row's state when you insert, move or remove.

```vue [app/components/TodoList.vue]
<script setup lang="ts">
import * as v from 'valibot'

const TodoSchema = v.object({
  todos: v.array(v.object({ label: v.pipe(v.string(), v.nonEmpty()) })),
})

const form = useForm({ schema: TodoSchema, initialInput: { todos: [{ label: '' }] } })
const todos = useFieldArray(form, { path: ['todos'] })
</script>

<template>
  <FForm :of="form" @submit="console.log">
    <div v-for="(key, index) in todos.items" :key="key">
      <FField v-slot="field" :of="form" :path="['todos', index, 'label']">
        <input v-model="field.input" v-bind="field.props">
      </FField>
      <button type="button" @click="remove(form, { path: ['todos'], at: index })">
        Remove
      </button>
    </div>

    <button type="button" @click="insert(form, { path: ['todos'], initialInput: { label: '' } })">
      Add
    </button>
  </FForm>
</template>
```

The array store has `items`, `errors`, `path`, `isTouched`, `isEdited`, `isDirty` and `isValid`. Change the array with the [array methods](/forms/methods#arrays).

## With Nuxt UI

Field stores bind straight to Nuxt UI inputs: `v-model` to `input`, and the first error to `UFormField`.

```vue [app/pages/profile.vue]
<script setup lang="ts">
const form = useForm({ schema: ProfileSchema })
const name = useField(form, { path: ['name'] })
const email = useField(form, { path: ['email'] })
</script>

<template>
  <FForm :of="form" class="space-y-4" @submit="console.log">
    <UFormField label="Name" :error="name.errors?.[0]">
      <UInput v-model="name.input" />
    </UFormField>
    <UFormField label="Email" :error="email.errors?.[0]">
      <UInput v-model="email.input" type="email" />
    </UFormField>
    <UButton type="submit" :loading="form.isSubmitting">Save</UButton>
  </FForm>
</template>
```

To render every field from the schema without writing them out, use [`<FAutoForm>`](/auto-form).

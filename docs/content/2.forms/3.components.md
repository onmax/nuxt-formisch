The module registers Formisch's three components under an `F` prefix. They render no markup of their own besides `<form>`, so you style the inputs.

## FForm

Wraps a native `<form>` with `novalidate`. On submit it prevents the page reload, validates, focuses the first invalid field if there is one, and otherwise calls `@submit` with the validated output.

```vue
<FForm :of="form" @submit="onSubmit">
  <!-- fields -->
</FForm>
```

| Prop / event | Type |
| --- | --- |
| `of` | `FormStore` from `useForm` |
| `@submit` | `(output, event) => void \| Promise<void>`. Type it with `SubmitHandler<typeof Schema>`, or `SubmitEventHandler` when you need the event. |

`form.isSubmitting` is `true` while an async handler runs. If the handler throws, its message lands in `form.errors`, so a failed request can show up without extra state:

```vue
<p v-if="form.errors">{{ form.errors[0] }}</p>
```

## FField

Gives its slot the [field store](/forms/composables#usefield) for one path.

```vue
<FField v-slot="field" :of="form" :path="['user', 'email']">
  <input v-model="field.input" v-bind="field.props" type="email">
  <p v-if="field.errors">{{ field.errors[0] }}</p>
</FField>
```

| Prop | Type |
| --- | --- |
| `of` | `FormStore` |
| `path` | A valid path into the schema, checked by TypeScript. |

## FFieldArray

Gives its slot the [field array store](/forms/composables#usefieldarray). Key each row by its entry in `items`.

```vue
<FFieldArray v-slot="todos" :of="form" :path="['todos']">
  <div v-for="(key, index) in todos.items" :key="key">
    <FField v-slot="field" :of="form" :path="['todos', index, 'label']">
      <input v-model="field.input" v-bind="field.props">
    </FField>
    <button type="button" @click="remove(form, { path: ['todos'], at: index })">
      Remove
    </button>
  </div>
  <p v-if="todos.errors">{{ todos.errors[0] }}</p>
</FFieldArray>
```

## With Nuxt UI

Use Nuxt UI inputs inside `<FField>` like any other input. `UFormField` shows the label and the first error:

```vue
<FForm :of="form" class="space-y-4" @submit="onSubmit">
  <FField v-slot="field" :of="form" :path="['email']">
    <UFormField label="Email" :error="field.errors?.[0]">
      <UInput v-model="field.input" type="email" @blur="field.props.onBlur" />
    </UFormField>
  </FField>

  <FField v-slot="field" :of="form" :path="['role']">
    <UFormField label="Role" :error="field.errors?.[0]">
      <USelect v-model="field.input" :items="['developer', 'designer', 'manager']" />
    </UFormField>
  </FField>

  <UButton type="submit" :loading="form.isSubmitting">Save</UButton>
</FForm>
```

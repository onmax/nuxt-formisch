The module was rewritten on top of Formisch 1 and Nuxt 4. Most apps need a handful of renames.

## Requirements

- Nuxt 4 only.
- Forms are Valibot-only. The module no longer looks for Zod or ArkType. `readValidatedFormBody` on the server still takes any [Standard Schema](https://standardschema.dev).
- You no longer need `@formisch/vue` in your own `package.json`.

## Server

`useFormValidation` is now `readValidatedFormBody`. Issue paths in `data.issues` are plain keys and indexes: `['members', 0, 'name']`. See [Server validation](/forms/server-validation).

```diff [server/api/login.post.ts]
- const data = await useFormValidation(event, LoginSchema)
+ const data = await readValidatedFormBody(event, LoginSchema)
```

## Composables and methods

`useFormFields` and `useNuxtUIField` are removed. `useField` takes the form and config directly now, and Nuxt UI inputs bind to the field store:

```diff
- const { field } = useFormFields(form)
- const email = useNuxtUIField(field('email'))
+ const email = useField(form, { path: ['email'] })
```

```diff
- <UFormField label="Email" :error="email.error">
-   <UInput v-model="email.modelValue" />
+ <UFormField label="Email" :error="email.errors?.[0]">
+   <UInput v-model="email.input" />
```

`getAllErrors` is gone in Formisch 1. Use `getDeepErrors(form)`.

## FAutoForm

| Before | After |
| --- | --- |
| `:initial-values` | `:initial-input` |
| `@submit="(data) => …"` | `@submit="(output, event) => …"`. `output` is typed from the schema, and an async handler is awaited. |
| `@error` | Removed. Errors show on the fields; read them from the exposed `form`. |
| No default button | A submit button renders unless you fill the `actions` slot. |
| `#actions="{ isDirty, isSubmitting, reset }"` | `#actions="{ form, reset }"`: use `form.isDirty`, `form.isSubmitting`. |
| `#field:email="{ field, store }"` | ``#[`field:email`]="{ field, path, form }"``, keyed by dotted path. |
| `#section:<name>` | Removed. Use `section` for headings and `field:` slots for custom markup. |
| `fieldConfig` keyed by top-level name | Keyed by dotted path without array indexes: `'address.city'`, `'members.name'`. |
| `v.metadata({ fieldType: 'json' })` | `v.metadata({ type: 'json' })` |

`FAutoFormField`, `FAutoFormObject` and `FAutoFormArray` are no longer registered.

## Theme

AutoForm theming moved from `appConfig.ui.autoForm*` to one set of slots under `appConfig.formisch.autoForm.slots`. See [Theming](/auto-form/theming) for the new slot names.

```diff [app/app.config.ts]
  export default defineAppConfig({
-   ui: {
-     autoForm: { root: 'space-y-8' },
-     autoFormArray: { item: 'bg-muted' },
-   },
+   formisch: {
+     autoForm: { slots: { root: 'space-y-8', arrayItem: 'bg-muted' } },
+   },
  })
```

## introspectSchema

`ResolvedField` changed shape: UI options sit on the field itself (`field.label`, not `field.ui.label`), nested fields are in `fields` (was `children`), array items in `item` (was `itemSchema`), picklists and enums are `type: 'enum'` (was `'picklist'`), and records are `type: 'json'`. Every field has a dotted `key`.

Every option has a default that fits most apps, so this is optional.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui', 'nuxt-formisch'],
  formisch: {
    imports: true,
    components: true,
    prefix: 'F',
    autoForm: true,
  },
})
```

| Option | Default | |
| --- | --- | --- |
| `imports` | `true` | Auto-imports the Formisch composables, methods and types. Set `false` to import them from `@formisch/vue` yourself. |
| `components` | `true` | Registers `Form`, `Field` and `FieldArray` with `prefix`. |
| `prefix` | `'F'` | Prefix for every component the module registers: `FForm`, `FField`, `FFieldArray`, `FAutoForm`. |
| `autoForm` | `true` when `@nuxt/ui` is in `modules` | Registers `<FAutoForm>` and auto-imports `introspectSchema` and the `FieldConfig` / `ResolvedField` types. Setting it to `true` without Nuxt UI fails the build. |

`jsonToValibotSchema` in the app and `readValidatedFormBody` in `server/` are always auto-imported.

## Types

The module exports its public types for use outside auto-imported code:

```ts
import type { AutoFormThemeConfig, FieldConfig, FormIssue, ModuleOptions, ResolvedField } from 'nuxt-formisch'
```

Also exported: `FieldConstraints`, `FieldOption`, `FieldType`, `JsonToValibotSchemaOptions` and `FormValidationErrorData`.

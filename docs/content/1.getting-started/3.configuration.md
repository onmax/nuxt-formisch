The module works without options. It looks at your project and registers what fits:

| Installed | Registered |
| --- | --- |
| always | Formisch composables, components (`F` prefix), methods and types, and `useFormValidation` in `server/` |
| `valibot` | `jsonToValibotSchema` |
| `@nuxt/ui` | `<FAutoForm>` and its parts, `useNuxtUIField`, `introspectSchema`, and the `FieldConfig` / `ResolvedField` types |

Without `valibot` the module logs a warning at startup: Formisch needs it to build forms.

## Options

Options go under the `formisch` key:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-formisch'],
  formisch: {},
})
```

There are no options yet.

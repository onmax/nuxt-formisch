Nuxt Formisch is a Nuxt module for [Formisch](https://formisch.dev), a schema-based, headless form library, with [Valibot](https://valibot.dev) schemas. It auto-imports Formisch's composables, components and methods, adds a server helper that validates request bodies with the same schema, and ships an AutoForm component for [Nuxt UI](https://ui.nuxt.com).

## Install

::steps
### Add the package

```bash [Terminal]
pnpm add nuxt-formisch valibot
```

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-formisch'],
})
```
::

That's all the setup. Next, [build your first form](/getting-started/first-form).

## What you get

| Where | Auto-imported |
| --- | --- |
| Composables | `useForm`, `useField`, `useFieldArray` |
| Components | `<FForm>`, `<FField>`, `<FFieldArray>` |
| Methods | `focus`, `getInput`, `setInput`, `getErrors`, `setErrors`, `reset`, `validate`, `submit`, `handleSubmit`, `insert`, `remove`, `move`, `swap`, `replace`, and the rest of the [Formisch methods](/forms/methods) |
| Types | `SubmitHandler`, `FormStore`, `FieldStore`, `ValidPath`, and friends |
| Server routes | `useFormValidation` |

Formisch's components are prefixed with `F` so they don't clash with your own `Form` or `Field` components.

## With Nuxt UI

If `@nuxt/ui` is installed, the module also registers [`<FAutoForm>`](/auto-form) and the `useNuxtUIField` helper. Nothing else to configure:

```bash [Terminal]
pnpm add @nuxt/ui
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui', 'nuxt-formisch'],
})
```

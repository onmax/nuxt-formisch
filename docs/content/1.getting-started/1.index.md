Nuxt Formisch is a Nuxt module for [Formisch](https://formisch.dev), a schema-based, headless form library, with [Valibot](https://valibot.dev) schemas. It auto-imports Formisch's composables, components, methods and types, adds a server helper that validates request bodies with the same schema, and ships an AutoForm component for [Nuxt UI](https://ui.nuxt.com).

It needs Nuxt 4.

## Install

::steps
### Add the package

```bash [Terminal]
pnpm add nuxt-formisch valibot
```

`@formisch/vue` comes with the module; you don't install it yourself.

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-formisch'],
})
```
::

That's all the setup. Next, [build your first form](/getting-started/first-form).

## What you get

| Where | Auto-imported |
| --- | --- |
| Composables | `useForm`, `useField`, `useFieldArray` |
| Components | `<FForm>`, `<FField>`, `<FFieldArray>` |
| Methods | `getInput`, `setInput`, `getErrors`, `setErrors`, `getDeepErrors`, `reset`, `validate`, `submit`, `handleSubmit`, `insert`, `remove`, and the rest of the [Formisch methods](/forms/methods) |
| Types | `FormStore`, `FieldStore`, `SubmitHandler`, `SubmitEventHandler`, `ValidPath`, and the other user-facing Formisch types |
| Utils | `jsonToValibotSchema` |
| Server routes | [`readValidatedFormBody`](/forms/server-validation) |

The components are prefixed with `F` so they don't clash with your own `Form` or `Field`. [Configuration](/getting-started/configuration) changes the prefix or turns parts off.

## With Nuxt UI

When `@nuxt/ui` is in `modules`, the module also registers [`<FAutoForm>`](/auto-form) and auto-imports `introspectSchema`:

```bash [Terminal]
pnpm add @nuxt/ui
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/ui', 'nuxt-formisch'],
})
```

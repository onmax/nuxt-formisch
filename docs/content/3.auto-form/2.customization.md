Schema metadata sets defaults that travel with the schema. `fieldConfig` overrides them for one form, slots replace the markup, and custom components replace a single input.

## fieldConfig

Keys are top-level field names.

```vue
<script setup lang="ts">
const fieldConfig = {
  email: { label: 'Work email', placeholder: 'you@company.com' },
  role: { section: 'Access', order: 1, disabled: !isAdmin.value },
  internalNotes: { hidden: true },
} satisfies Record<string, FieldConfig>
</script>

<template>
  <FAutoForm :schema="UserSchema" :field-config="fieldConfig" @submit="onSubmit" />
</template>
```

| Option | Type | |
| --- | --- | --- |
| `label` | `string` | Label text. |
| `description` | `string` | Help text. |
| `placeholder` | `string` | Placeholder. |
| `unit` | `string` | Suffix next to the input. |
| `section` | `string` | Section heading to group under. |
| `order` | `number` | Sort order. Lower comes first; fields without one count as `0` and keep schema order. |
| `hidden` | `boolean` | Leaves the field out. |
| `disabled` | `boolean` | Disables the input. |
| `colSpan` | `number` | Grid columns to span. |
| `component` | `Component` | Replaces the input. See below. |
| `componentProps` | `Record<string, unknown>` | Extra props for `component`. |

`FieldConfig` and `ResolvedField` are auto-imported types.

## Custom components

A custom component replaces the input inside the field's `UFormField`, so the label, help text and error stay. It gets `modelValue` and `disabled`, plus `componentProps`, and emits `update:modelValue`:

```vue [app/components/ColorSwatches.vue]
<script setup lang="ts">
defineProps<{ swatches: string[], disabled?: boolean }>()
const color = defineModel<string>()
</script>

<template>
  <div class="flex gap-2">
    <button
      v-for="swatch in swatches"
      :key="swatch"
      type="button"
      class="size-8 rounded-md"
      :class="{ 'ring-2 ring-primary': color === swatch }"
      :style="{ backgroundColor: swatch }"
      :disabled="disabled"
      @click="color = swatch"
    />
  </div>
</template>
```

```vue
<script setup lang="ts">
import ColorSwatches from '~/components/ColorSwatches.vue'

const fieldConfig = {
  accent: { component: ColorSwatches, componentProps: { swatches: ['#10b981', '#3b82f6', '#f43f5e'] } },
}
</script>
```

## Slots

| Slot | Scope | Replaces |
| --- | --- | --- |
| `field:<name>` | `{ field, store }` | One field. `store` is its Formisch [field store](/forms/composables#usefield). |
| `section:<name>` | `{ fields }` | A whole section and its heading. |
| `actions` | `{ isDirty, isSubmitting, reset }` | The area after the fields. Empty by default. |

```vue
<FAutoForm :schema="PostSchema" @submit="onSubmit">
  <template #field:body="{ field, store }">
    <UFormField :label="field.ui.label" :error="store.errors?.[0]">
      <UTextarea v-model="store.input" :rows="8" autoresize />
    </UFormField>
  </template>

  <template #actions="{ isDirty, isSubmitting, reset }">
    <div class="flex justify-end gap-2">
      <UButton variant="ghost" :disabled="!isDirty" @click="reset">Reset</UButton>
      <UButton type="submit" :loading="isSubmitting">Publish</UButton>
    </div>
  </template>
</FAutoForm>
```

AutoForm follows Nuxt UI's theming model. Each part has named slots with Tailwind classes. Classes are applied in order: the defaults, then `app.config.ts`, then the `ui` prop, then `class`.

## Global

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    autoForm: {
      root: 'space-y-8',
      sectionTitle: 'text-base font-semibold text-highlighted mb-4',
    },
    autoFormObject: {
      root: 'col-span-full space-y-3',
    },
  },
})
```

## Per instance

```vue
<FAutoForm :schema="schema" :ui="{ grid: 'gap-2' }" class="max-w-lg" />
```

## Slots and defaults

### autoForm

| Slot | Default |
| --- | --- |
| `root` | `space-y-6` |
| `section` | |
| `sectionTitle` | `text-lg font-medium mb-3` |
| `grid` | `grid gap-4`, plus `sm:grid-cols-2` and up for `columns` |

### autoFormField

| Slot | Default |
| --- | --- |
| `root` | |
| `wrapper` | `flex items-center gap-2` |
| `unit` | `text-sm text-muted` |

### autoFormObject

| Slot | Default |
| --- | --- |
| `root` | `col-span-full rounded-lg border border-default p-3 space-y-3 bg-muted/5` |
| `legend` | `text-sm font-medium px-2` |
| `grid` | `grid gap-3` |

### autoFormArray

| Slot | Default |
| --- | --- |
| `root` | `col-span-full space-y-2` |
| `legend` | `text-sm font-medium text-muted mb-2` |
| `item` | `flex items-start gap-2 p-2 bg-muted/10 rounded-md` |
| `grid` | `flex-1 grid gap-2` |
| `removeButton` | `shrink-0 mt-6` |
| `addButton` | `mt-2` |

Inputs are plain Nuxt UI components, so `ui.input`, `ui.select`, `ui.switch` and `ui.formField` in `app.config.ts` restyle them as they do everywhere else in your app.

AutoForm's markup has named slots, each with Tailwind classes, the way Nuxt UI components do. Classes merge with tailwind-merge in this order: the defaults, `app.config.ts`, then the `ui` prop (and `class` on the root).

## Global

```ts [app/app.config.ts]
export default defineAppConfig({
  formisch: {
    autoForm: {
      slots: {
        root: 'space-y-8',
        sectionTitle: 'text-lg',
        arrayItem: 'bg-muted',
      },
    },
  },
})
```

The `formisch` key is typed, so your editor completes the slot names.

## Per instance

```vue
<FAutoForm :schema="schema" :ui="{ grid: 'gap-2', actions: 'justify-end' }" class="max-w-lg" @submit="save" />
```

## Slots

| Slot | Default | Element |
| --- | --- | --- |
| `root` | `space-y-6` | The `<form>`. |
| `section` | `space-y-3` | A section and its heading. |
| `sectionTitle` | `text-base font-semibold text-highlighted` | Section heading. |
| `grid` | `grid gap-4`, plus `sm:grid-cols-*` from `columns` | Field grid, also inside objects. |
| `object` | `col-span-full space-y-3 rounded-lg border border-default p-4` | Nested object fieldset. |
| `objectLegend` | `px-1 text-sm font-medium text-highlighted` | Its legend. |
| `array` | `col-span-full space-y-2` | Array wrapper. |
| `arrayLegend` | `text-sm font-medium text-highlighted` | Array label. |
| `arrayItem` | `flex items-start gap-2 rounded-md bg-elevated/50 p-2` | One row. |
| `arrayItemFields` | `grid flex-1 gap-3`, plus columns | The fields in a row. |
| `arrayRemove` | `shrink-0` | Remove button. |
| `arrayAdd` | | Add button. |
| `input` | `w-full` | `UInput`, `USelect` and `UTextarea`. |
| `json` | `w-full font-mono text-xs` | JSON textarea. |
| `unit` | `text-sm text-muted` | Unit text. |
| `error` | `text-sm text-error` | Form and array errors. |
| `actions` | `flex gap-2` | The actions area. |

Inputs are Nuxt UI components, so `ui.input`, `ui.select`, `ui.switch` and `ui.formField` in `app.config.ts` restyle them as everywhere else in your app.

## Component detection

If you turn on Nuxt UI's `experimental.componentDetection`, Nuxt UI only generates CSS for the components it finds in your code, and misses the ones AutoForm renders. Add the module to Tailwind's sources:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@source "../../../node_modules/nuxt-formisch/dist/runtime";
```

The path is relative to the CSS file.
